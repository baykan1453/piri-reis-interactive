# Piri-Reis Interactive Map

Developed in 2024 for a national technology competition (Teknofest).  
An interactive educational project designed to help students learn about **Piri Reis** and his 1513 world map, available as both a **mobile app** and a **web (HTML-based) version**.

## Overview
- Developed in 2024 during my high school years.
- Participated in Teknofest as part of this personal project.
- The project includes both **web** and **mobile** applications.
- **Visual Studio** was used for the web application and **Kodular** for the mobile application.

## Purpose
- The goal of this project was to create an interactive application related to **Piri Reis**, aiming to **educate and engage users**.

## Web Application
- Files located in: /web/
- Open `index.html` in a web browser to explore the application.

## Mobile Application
- Source file located in: /mobile/pirireis.aia
- This is a Kodular / MIT App Inventor project file.
- To open or modify the mobile app:
  1. Go to https://kodular.io/ or https://appinventor.mit.edu/
  2. Import the `.aia` file
  3. Build an APK or test the app directly in the platform

## About Piri Reis
- Piri Reis was an Ottoman admiral, navigator, and cartographer.
- The project draws inspiration from his maps and voyages to create educational content.
